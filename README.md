# **THIS MOD ONLY NEEDS TO BE ON THE HOST! UNMODDED CLIENTS CAN PLAY!**



## Big Lobbies



## Mod made by "AdamMady" you can join my discord here to give me feedback or give me new mod ideas: https://discord.gg/5z3WvVhxCf



## Features:



#### Host bigger lobbies! Defaults to 50 players, adjustable up to 100 through Mod Settings.



#### Voice support beyond the normal player limit! Each player gets voice slots for nearby speakers instead of spending them on people too far away to hear.



#### Supports people actively using megaphones, walkie-talkies and radio stations!



#### Change player limit, hearing distance and network update cap while playing!



## Settings:



#### Get the Mod Settings Menu mod to change these settings in-game. Without it, settings can be changed in BepInEx/config/AdamMady.BiggerWalkAndTalk.cfg.



#### MaxPlayerCount: 50 by default.



#### QuietThreshold: 0.004 by default. Stops player from being heard until they go above this volume.



#### Update Cap Hz: Normal by default. Movement will look less smooth the lower it is, Can improve network traffic.



#### Hearing Distance: 24 metres by default, Can improve network traffic 



## Important:



#### Unmodded clients still have a limited number of voice slots. This mod reallocates those slots; it does not let everyone in a huge crowd speak simultaneously. Instead it splits closer players into smaller talking channels.



#### Bigger lobbies need more host upload bandwidth and processing power.



## Installation:



#### Step 1: Install BepInEx 6 IL2CPP for Windows x64 from https://builds.bepinex.dev/projects/bepinex_be and extract it into the game directory. Launch the game once to finish setup, then close it.



#### Step 2: Copy the BepInEx folder included with this mod into the game directory. If updating, replace your previous BiggerWalkAndTalk.dll. Disable Bigger Walk and the old event version so only one lobby-capacity mod is loaded.



#### Step 3: Host a game and invite your friends! Only the host needs this mod. Mod Settings Menu is optional.
