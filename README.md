## Manual Installation
Only the host needs to install!

1.) Download Bepinex from [here](https://builds.bepinex.dev/projects/bepinex_be/785/BepInEx-Unity.IL2CPP-win-x64-6.0.0-be.785%2B6abdba4.zip) <br>
2.) Extract the contents of that zip into your game directory (default: C:\Program Files (x86)\Steam\steamapps\common\Big Walk) resulting in a folder that has the following files: <br>
![image](https://github.com/user-attachments/assets/403d9a1d-16a4-409c-a046-bc56141ac0ca) <br>
3.) Start the game and close it again, this does the first time set up for Bepinex. <br>
- Linux users: set the launch option `WINEDLLOVERRIDES="winhttp=n,b" %command%` before running the game.
  
4.) Navigate to ...\Big Walk\BepInEx\plugins, Download and extract the Bigger_Walk.dll from releases. <br>
5.) Run the game <br>
